### 1번 항목에 대한 주석

이 저장소의 커밋 이력·문서·로그 전체를 검색했으나 **호스트 이전에 대한 직접 기록을
찾지 못했다.** 확인한 범위는 다음과 같다.

- 커밋 메시지 및 diff 내용 검색: `마이그레이션` / `migration` / `서버 이전` / `호스트 이전` / `새 VM`
- 대체 호스트 후보 검색: Lightsail / Oracle / Vultr / NCloud / AWS / EC2 / e2-medium / e2-micro
- 인프라 기술 변화 추적: `e2-small` 은 최초 등장(`63479d6`, 2026-02-23)부터 운영 종료까지
  동일하게 유지되며, 다른 사양·다른 호스트로 바뀐 흔적이 없다.

따라서 이 표에는 **시점·소요시간·결과 수치를 적지 않았다.** 이전이 이 저장소 바깥
(예: 호스트 프로비저닝, 별도 인프라 저장소)에서 이뤄졌다면 그 기록을 근거로 보강해야 한다.

## 재현 방법

```bash
git clone https://github.com/zln02/quant-agent.git && cd quant-agent
cp .env.example .env    # 값은 비어 있음 — 필요한 항목만 채운다
docker compose up -d
```

`DRY_RUN=true` 가 기본값이다. 실제 주문 경로를 활성화하지 않는 한
거래소로 주문이 나가지 않는다.
