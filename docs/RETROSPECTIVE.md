## 재현 방법

```bash
git clone https://github.com/zln02/quant-agent.git && cd quant-agent
cp .env.example .env    # 값은 비어 있음 — 필요한 항목만 채운다
docker compose up -d
```

`DRY_RUN=true` 가 기본값이다. 실제 주문 경로를 활성화하지 않는 한
거래소로 주문이 나가지 않는다.
